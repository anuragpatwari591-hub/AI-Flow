# Fonts
Drop additional licensed font files here and register them in `config/fonts.yaml` with `license`, `license_ref`
and `source`. The renderer refuses any font whose registry entry lacks a license.
Bundled-by-reference system fonts (Inter, Liberation Serif - SIL OFL 1.1; DejaVu - Bitstream Vera) are listed with
their license references; `reelstudio fonts` prints the full license table, and every render stores the font id
used in its render spec.
